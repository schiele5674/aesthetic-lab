# Style Preference Bias Coding v0.1

## 1. Coding Purpose

To examine whether AI models repeatedly favor or reject particular visual styles without sufficient consideration of the specified design goal.

## 2. Coding Scale

| Score | Meaning |
|---|---|
| 0 | No observable bias indicator |
| 1 | Possible bias indicator; insufficient evidence |
| 2 | Clear bias indicator in this individual response |

A score of 2 does not prove stable model-level bias.

## 3. Coding Records

Detailed coding records will be added one by one after examining the original AI responses.

## 4. Cross-Case Analysis

Potential recurring patterns will be examined across different images, design goals, and models.

No stable model-level bias will be claimed without repeated supporting evidence.
