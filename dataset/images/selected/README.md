# Selected Experimental Images

This directory contains the four images selected for the Aesthetic Lab exploratory pilot study.

## Selected Images

- IMG02
- IMG05
- IMG07
- IMG08

## Selection Information

The four images were selected from an initial candidate pool of eight images.

They will be evaluated under two different design goals:

- G01 — Contemporary Cultural Exhibition
- G02 — Urban Youth Music Festival

Each image will be evaluated by two models:

- ChatGPT (GPT-6)
- DeepSeek (DeepSeek-V4.1-Flash)

## Research Notes

- Image style descriptions are provisional observations, not ground-truth labels.
- The original design intentions of the images are not assumed.
- All images are evaluated against externally assigned design goals.
- Original image files are preserved separately.
