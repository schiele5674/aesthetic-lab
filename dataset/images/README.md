# Pilot Image Dataset

This directory is reserved for the eight candidate images used in the Aesthetic Lab pilot study.

## 1. Image File Naming Convention

Image files should use the following names:

- IMG01
- IMG02
- IMG03
- IMG04
- IMG05
- IMG06
- IMG07
- IMG08

Recommended file format: JPG or PNG.

Example:

`IMG01.jpg`

## 2. Image Management Rules

- Each image must correspond to one unique Image ID.
- Image IDs must match the Image Source Register.
- Original image files should be preserved without unrecorded modifications.
- Any cropped, resized, or edited version must be documented.
- Image source and creator information must be recorded.

## 3. Copyright and Usage Rights

Images must not be publicly redistributed until their usage rights have been verified.

For each image, record:
- Original source URL
- Creator or institution
- License or rights statement
- Verification status

If redistribution permission is unclear, retain the source link and do not upload the original image file to this public repository.

## 4. Current Status

Eight candidate images have been selected for initial visual screening.

Their source and rights information is still being reviewed.

This directory currently serves as an organizational reference. The presence of an image ID does not mean that the image has been approved for public redistribution.
