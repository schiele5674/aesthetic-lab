# Prompt Version Control

## Aesthetic Lab — Pilot Study V0.1

### Official Evaluation Prompt

The official prompt for the current pilot study is:

`visual-evaluation-prompt-v0.1.md`

### Earlier Development Version

`goal-oriented-evaluation-prompt-v1.md` is retained as an earlier development document.

It is not used for the current pilot data collection.

### Consistency Rules

1. Use the official prompt for all AI evaluations in this pilot study.
2. Do not change the prompt during data collection.
3. Record the prompt version in every AI evaluation record.
4. If the prompt is revised, assign a new version number and document the changes.
5. Do not combine evaluation results from different prompt versions without explicitly documenting the difference.

### Research Note

This version control decision is intended to improve consistency and traceability. It does not imply that the prompt has been scientifically validated.
