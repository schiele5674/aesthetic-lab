# Prompt bank

Store each benchmark prompt with a stable task ID, track, exact wording, constraints, and intended evaluation criteria.

Suggested IDs:
- VIS-001 to VIS-005
- LIT-001 to LIT-005
- INT-001 to INT-005

Keep prompts unchanged within a comparison round. If a prompt is revised, create a new version (for example, VIS-001-v2) rather than overwriting the original.
